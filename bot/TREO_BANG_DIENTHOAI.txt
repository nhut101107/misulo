## LỰA CHỌN 3: CLOUD VPS VIỆT NAM (30k - 50k/THÁNG) - KHUYÊN DÙNG SỐ 1 KHI LÀM ĂN LÂU DÀI

Nếu sếp muốn bán key nghiêm túc, dữ liệu đơn hàng và số dư ví của khách không bao giờ sợ mất hay reset thì phương án thuê VPS cỏ là đỉnh nhất.

### Cách quản lý VPS 100% bằng điện thoại:
1. Thuê 1 con VPS Ubuntu rẻ nhất ở VN (Vietnix, CloudFly, TinoHost, vHost... giá từ 30.000đ - 50.000đ/tháng, quét mã QR thanh toán).
2. Nhà cung cấp gửi cho sếp: **IP**, **User** (thường là `root`), và **Mật khẩu**.
3. Trên điện thoại (Android hoặc iPhone), vào App Store / CH Play tải app **Termius** (miễn phí).
4. Mở Termius -> Bấm dấu `+` -> Chọn `New Host`:
   - Hostname: Nhập địa chỉ IP
   - Username: `root`
   - Password: Nhập mật khẩu
   - Bấm Save rồi bấm kết nối.
5. Trong màn hình đen của Termius, sếp chỉ cần dán lệnh cài đặt 1-click này:
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_20.x | bash - && apt-get install -y nodejs git && npm install -g pm2
   git clone https://github.com/nhut101107/misulo.git mnhutbot
   cd mnhutbot/MicuBot
   npm install
   pm2 start server.js --name mnhut-vip
   pm2 save
   pm2 startup
   ```
6. Xong! Bot sẽ chạy vĩnh viễn trong VPS. Sếp tắt app Termius, tắt nguồn điện thoại thì bot vẫn bán key và duyệt tiền bình thường suốt 24/7!
